# Integração de IA

A integração permite perguntas em linguagem natural sobre os dados do sistema, por meio do módulo previsto na disciplina.

## Acesso

O escopo prevê uma opção dedicada no menu para consultas em linguagem natural.

## Interface e uso

Entradas, respostas e requisitos de execução dependem da interface fornecida em aula. O módulo ainda não foi disponibilizado.

As consultas utilizam dados fictícios do laboratório. A disponibilidade da função depende da integração desse módulo à aplicação.
